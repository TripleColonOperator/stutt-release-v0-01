# Security

STUTT is an experimental public beta. Its command allow-list is a prototype
boundary, not a security certification. Model mode can send input to the
configured endpoint. Use sanitized inputs when testing unfamiliar services.

If this repository has GitHub private vulnerability reporting enabled, use its
Security tab to report a suspected vulnerability privately. Include the affected
version, impact, and minimal reproduction steps with sensitive data removed.

If private reporting is unavailable, open a sanitized issue saying that a
potential security problem needs a private reporting channel. Do not include
exploit details, working exploit code, credentials, private prompts, or other
sensitive data in a public issue. Wait for a maintainer to establish a private
channel before sharing those details.

When possible, include whether the issue also occurs in the latest beta. No
response-time or security-audit guarantee is offered.
